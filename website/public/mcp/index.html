Get connected

One setup. Your agent. Your workflow.

REA setup detects supported clients, shows the proposed configuration and asks before applying changes. It can install the matching investigation skill too.

  1. 01
    Run setup

    Choose your agent and review its setup plan.

  2. 02
    Approve the changes

    REA backs up existing configuration before updating it.

  3. 03
    Restart and investigate

    Ask your agent to check its REA connection, then give it a scoped question.

Designed to keep you in control

Your targets and your choices stay yours.

⌂

Local by design

REA is a local tool. Your agent connects to the REA process configured on your machine, not a REA-hosted MCP endpoint.

◎

You select the target

Give REA a target and a question. Bring the tools and analysis engines your task requires.

◷

Actions are not assumed

Analysis is not the same as execution. Runtime tools have distinct effects; keep them within the scope you authorize.

▤

Evidence stays traceable

Keep source identities, tool outputs, limitations and unknowns available when you review an answer.

Native engines such as Hopper, Ghidra and IDA are bring-your-own. Setup does not install or upgrade Ghidra or IDA.
